# 🐍 Snake

A classic Snake game built with HTML5 Canvas.

**[Play it live →](https://igloobot1.github.io/snake_game/)**

## Features

- Dark theme with ice-blue accents
- Arrow keys, WASD, and swipe controls
- Score tracking with localStorage high score
- Speed increases as you score
- Mobile-friendly, responsive canvas

## Run Locally

Open `index.html` in a browser. No build step needed.
